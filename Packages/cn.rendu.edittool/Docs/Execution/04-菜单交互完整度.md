## 步骤 4.1 — 右键上下文菜单（§3.3 第 3 项）

### 4.1.1 数据 API
- `MenuTreeItem` 新增：
```csharp
public sealed class ContextMenuEntry
{
    public string Text;
    public Action<MenuTreeItem> Action;
    public Func<bool> Enabled;   // null 视为可用
}

public readonly List<ContextMenuEntry> ContextMenuEntries = new();

public MenuTreeItem AddContextMenu(string text, Action<MenuTreeItem> act, Func<bool> enabled = null)
{
    ContextMenuEntries.Add(new ContextMenuEntry { Text = text, Action = act, Enabled = enabled });
    return this;
}
```

### 4.1.2 行挂接
- `BuildMenuItems` 建行时：
```csharp
row.RegisterCallback<ContextualMenuPopulateEvent>(evt =>
{
    foreach (var e in item.ContextMenuEntries)
        evt.menu.AppendAction(e.Text,
            _ => e.Action?.Invoke(item),
            e.Enabled?.Invoke() ?? true ? DropdownMenuAction.Status.Normal : DropdownMenuAction.Status.Disabled);
});
```
- 无条目时不弹菜单。

### 4.1.3 验证
- 右键出现注册项、点击执行、`Enabled` 置灰生效；无条目节点右键无反应。

## 步骤 4.2 — 拖拽（§3.3 第 4 项）

拍板为两类，分别落地。

### 4.2.1 菜单项重排（树内拖动）
- `MenuTreeItem` 加 `public bool Draggable;`（默认 false，opt-in）。
- `MenuTree` 加：
```csharp
public event Action ItemsReordered;

/// <summary>把 item 移到 newParent（null = 根）下第 index 位。</summary>
public void MoveItem(MenuTreeItem item, MenuTreeItem newParent, int index)
{
    // 从原 Parent/根列表移除 → 插入目标位（目标列表去重语义与 Add 一致）→ ItemsReordered?.Invoke()
}
```
- 行拖动：`PointerDownEvent` 记起点 → `PointerMoveEvent` 位移 > 4px 且 `item.Draggable` → `DragAndDrop.PrepareStartDrag()` + `SetGenericData("RD.MenuTreeItem", item)` + `StartDrag`。
- 目标行 `DragUpdatedEvent/DragPerformEvent`：按指针在行上/下半段决定插入位置，`Perform` 时调 `MoveItem`；`SetGenericData` 不匹配的拖拽直接放行。

### 4.2.2 外部对象拖入
- `m_MenuPanel` 注册 `DragUpdatedEvent/DragPerformEvent`。
- `DragAndDrop.objectReferences` 非空时：悬停节点高亮，`Perform` 时调用虚方法：
```csharp
/// <summary>外部 Unity 对象拖到 target 节点上；默认不接收，子类重写决定语义。</summary>
protected virtual void OnDropExternalObjects(MenuTreeItem target, Object[] objects) { }
```

### 4.2.3 验证
- `Draggable` 节点可重排且数据顺序与 UI 一致、`ItemsReordered` 触发；拖 `Object` 到节点触发回调；无拖拽状态残留。

## 步骤 4.3 — 每项自定义绘制（§3.3 第 6 项）

当前行模板写死（foldout + 图标 + 文字，在 `BuildMenuItems` 内）。

### 4.3.1 数据 API
- `MenuTreeItem` 新增：
```csharp
/// <summary>在默认行(foldout+图标+名称)之后追加自绘内容（徽标/内联按钮/进度条）；null 走默认。</summary>
public Action<VisualElement> CustomDraw;

/// <summary>行高，默认 24（MenuRowHeight）；徽标等双行内容可调。</summary>
public float RowHeight = 24f;
```

### 4.3.2 行构建接入
- `BuildMenuItems` 中：`row.style.height = item.RowHeight;` 替换常量；在 `row.Add(label)` 之后 `item.CustomDraw?.Invoke(row);`。

### 4.3.3 验证
- 示例窗口给某项加徽标；未设置的项与现状像素级一致。

## 步骤 4.4 — 多选 UI 语义（§3.3 第 5 项）

数据层 `MenuTreeSelection.Select(MenuTreeItem[])` 已支持，仅补 UI 与增量 API。

### 4.4.1 `MenuTreeSelection` 补增量 API
```csharp
public void ToggleSelect(MenuTreeItem item)   // 已选中则移除，否则追加
public void AddToSelection(MenuTreeItem item) // 追加（幂等）
```

### 4.4.2 行点击修饰键语义（拍板）
- 普通左键：`Select(item)`（现状不变），并记录 `m_LastClicked`。
- `Ctrl/⌘ + 左键`：`ToggleSelect(item)`。
- `Shift + 左键`：以 `m_LastClicked` 为锚，在 `m_VisibleOrder` 中取区间组 `items[]` 调 `Select(MenuTreeItem[])`。
- 右栏**维持 `SelectedValue`（首项）**。多对象绘制不上提引擎（设计文档 §2.6 D5），本步与 03 档步骤 3.6 无依赖。

### 4.4.3 高亮
- `RefreshMenuSelection` 本就遍历全表按 `IsSelected` 刷色，多选天然生效。

### 4.4.4 验证
- Ctrl 多选（追加/反选）、Shift 范围选、普通单选互斥；高亮正确；右栏画首项。
