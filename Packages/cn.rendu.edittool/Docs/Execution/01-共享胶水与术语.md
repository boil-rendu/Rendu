## 1.2 新增契约条款（本轮校订补入设计文档 §2.3.2）

1. **必须成对**：回调风格下 `BeginChange` 返回的 `ChangeScope` 被丢弃，脏标记靠 `EndChange` 补上；只用其一会丢一半。宿主不得拆开用。
2. **传序列化根，不传引擎回传的 owner**：引擎回调的 `owner` 可能是组件内部的普通 C# 对象（如 `UIData`），对它 Undo / SetDirty 无效。宿主一律传自己的 `target`。
3. **纯内存窗口规则**：仅当宿主确实不编辑可序列化对象时方可传 `null`，并在宿主 XML 注释写明前提。EditTool 日后出现"编辑序列化资产"的窗口时，直接接这对胶水，不重抄旧实现。
