## 步骤 5.1 — 展开 / 选中态持久化（§3.3 第 8 项）

> 部分已落地：搜索关键字 `m_Filter` 在 `RebuildMenuTree` 中回填并重套过滤。`Toggled` / 选中态仍未持久化，本步补齐。

### 5.1.1 拍板
- 按 `MenuTree.ConfigID`（字段已存在）存 **`SessionState`（会话级）**：
  - `RD.MenuTree.{ConfigID}.Expanded`：展开项路径 `';'` 连接；
  - `RD.MenuTree.{ConfigID}.Selected`：选中项路径。
- 路径由 `Parent` 链拼 `'/'`（复用 `MenuTreePathUtil`）。

### 5.1.2 API 与接入
- `MenuTree` 新增 `public void SaveState()` / `public void RestoreState()`。
- `RebuildMenuTree`：重建前 `SaveState()`，重建并 `BuildMenuUI` 后 `RestoreState()`——直接治好"重建树丢 `Toggled`/选中"。
- 首次构建（`EnsureMenuTree`）后也调 `RestoreState()`。

### 5.1.3 验证
- 重建后展开/选中保持；不同 `ConfigID` 互不串台；`ConfigID` 为空时静默跳过。

## 步骤 5.2 — 项置灰 / 禁用（§3.3 第 10 项）

### 5.2.1 API
- `MenuTreeItem` 加 `public bool Enabled { get; set; } = true;`

### 5.2.2 行为（拍板）
- 行点击回调（在 `BuildMenuItems` 内注册）首行 `if (!item.Enabled) return;`。
- `RefreshMenuSelection`：disabled 项文字用 `EditorStyles.label.normal.textColor × 0.5 alpha`，选中底纹不施加。
- 右键条目自身禁用已由 04 档 `ContextMenuEntry.Enabled` 支持，二者独立叠加。

### 5.2.3 验证
- 禁用项点击无效、视觉置灰；键盘导航跳过——02 档的 `OnMenuKeyDown` 已就位，`Enabled` 落地后在其移动分支里过滤即可（并入本步）。

## 步骤 5.3 — 面包屑 / 标题栏（§3.3 第 9 项）

### 5.3.1 拍板
- 默认**关闭**：`MenuEditorWindow` 加 `protected virtual bool ShowBreadcrumbs => false;`。

### 5.3.2 落地
- 开启时在右栏 `scroll` 上方加路径条：按 `SelectedValue` 的 `Parent` 链画每段为 `Button`。
- 点击某段 → `MenuTree.SelectMenuItem(该段路径)`（已有按路径选中）。
- `OnMenuSelectionChanged` 时刷新路径条内容。

### 5.3.3 验证
- 开启后显示 `A / B / C`，点击 `A` 选中并滚到 A；默认窗口不出现该条。

## 步骤 5.4 — 类型自动图标（§3.3 第 11 项）

### 5.4.1 拍板
- **opt-in**：`MenuTree` 加 `public bool AutoIcons;`（默认 `false`，保持现有确定性图标行为不变）。

### 5.4.2 落地
- `MenuTree.Add(menuPath, value, icon)` 中：`AutoIcons && icon == null && value is UnityEngine.Object uo` → `item.Icon = AssetPreview.GetMiniThumbnail(uo);`
- 显式传入的 icon 永远优先。

### 5.4.3 验证
- 开启后 `UnityEngine.Object` 节点自动带缩略图；显式 icon 不被覆盖；默认行为不变。

## 步骤 5.5 — 大数据树虚拟化（§3.3 第 12 项）

### 5.5.1 拍板：**不实现（明确决议，非遗留）**
- 理由：现有菜单树为模块级规模（几十~几百节点），`BuildMenuItems` 全量递归构建成本可忽略；UIElements 无可直接复用的 TreeView，自研虚拟化收益为负。
- 保护措施：`BuildMenuItems` 递归计数，总节点超 **2000** 时 `Debug.LogWarning`。
- 若未来真实超限，再基于 `ScrollView` + 行定位复用做虚拟化，届时另立执行文档。

### 5.5.2 验证
- 大树构建时出现规模告警；正常规模无噪音。

## 步骤 5.6 — 双击确认 vs 单击选中（§3.3 第 13 项）

### 5.6.1 拍板
- 默认保持**单击选中**（现状不变）。
- opt-in：`MenuTree` 加 `public bool ActivateOnDoubleClick;`（默认 `false`）。
- 为 `true` 时：单击仅选中并高亮，**右栏不刷新**；双击（`ClickEvent { clickCount == 2 }`）才 `RedrawContent()` 并 `Activate(item)`。
- 为 `false` 时：双击仍额外触发一次 `ItemActivated`（单击选中行为不变）。

### 5.6.2 落地
- 行 `ClickEvent` 回调（`BuildMenuItems` 内）：按 `clickCount` 分支，双击分支调 `Activate`；`ActivateOnDoubleClick` 时在 `OnMenuSelectionChanged` 内拦截右栏刷新。

### 5.6.3 验证
- 默认行为与现状一致；开启后双击才切换右栏；Enter 与双击共用 `ItemActivated`。
