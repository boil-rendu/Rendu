## 2.4 运行时验收（未做 —— 需人工跑 Unity，静态核实不能替代）

- 输入关键字 → 树过滤、命中项祖先自动展开；清空 → 恢复；**无重建闪烁**。
- 纯键盘可遍历：Up/Down/Home/End/首字母定位/Enter 激活（Enter 触发 `ItemActivated`）。
- 搜索框内打字**不被键盘导航拦截**（`evt.target is TextField` 守卫生效）。
- 长菜单选中底部项 / 键盘移到不可见项 → 自动滚入视口。
- 鼠标行为不回归：单击选中、右栏刷新、折叠箭头正常。
- **重建树后**：搜索关键字回填、树的显隐与关键字一致（不出现"框里没字、树却被过滤着"）。
